# AGENTS.md

Este es el repo de entregables de **TIMMD**.

Antes de hacer cualquier cambio, **leé [`README.md`](README.md) y [`CONTRIBUTING.md`](CONTRIBUTING.md)**: ahí está toda la información sobre cómo sumar nuevo contenido a los entregables (reglas, formato del registro y flujo de PR).

En resumen:
- Los proyectos se agregan editando `data/entregables.yaml`, **nunca el `README.md` a mano** (se regenera con `uv run scripts/build.py readme`).
- Los cambios se integran con un **pull request**, siguiendo los pasos de `CONTRIBUTING.md`.
